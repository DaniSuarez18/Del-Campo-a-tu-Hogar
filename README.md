# 🌾 Del Campo a tu Hogar

Plataforma web de comercio justo diseñada para conectar directamente a los pequeños productores lácteos artesanales (leche, yogurt, arequipe) con los consumidores finales, reduciendo intermediarios y garantizando precios justos.

---

## 🛠️ Tecnologías Utilizadas

* **Frontend:** React, Vite, Tailwind CSS / JavaScript / TypeScript
* **Backend:** Node.js / Express / NestJS
* **Base de Datos:** PostgreSQL / Supabase
* **Control de Versiones:** Git & GitHub

---

## 📁 Estructura del Repositorio

El proyecto está organizado en una arquitectura de monorepositorio:

```text
Del-Campo-a-tu-Hogar/
├── backend/    # Servidor, API REST, modelos de datos y autenticación
├── frontend/   # Interfaz de usuario, componentes y vistas de la aplicación
└── README.md   # Documentación principal del proyecto

## 🚀 Guía de Instalación y Ejecución Local

1. Clonar el repositorio

git clone [https://github.com/DaniSuarez18/Del-Campo-a-tu-Hogar.git](https://github.com/DaniSuarez18/Del-Campo-a-tu-Hogar.git)
cd Del-Campo-a-tu-Hogar

2. Configurar el Backend

cd backend
npm install
npm run dev

3. Configurar el Frontend

cd ../frontend
npm install
npm run dev
