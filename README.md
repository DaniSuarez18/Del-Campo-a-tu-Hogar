# 🐄 Del Campo a tu Hogar

¡Bienvenido al repositorio oficial de **Del Campo a tu Hogar**! Este es un aplicativo web diseñado para conectar directamente a los productores lácteos con los consumidores finales, reduciendo intermediarios y garantizando frescura y precios justos.

## 🚀 Demo
Puedes ver el aplicativo funcionando aquí: 
[https://DaniSuarez18.github.io/Del-Campo-a-tu-Hogar/](https://DaniSuarez18.github.io/Del-Campo-a-tu-Hogar/)

## 📝 Descripción del Proyecto
Este proyecto nace como una iniciativa académica para la facultad de Ingeniería de Sistemas y computación. El objetivo es reducir intermediarios y acercar a los campesinos locales con los consumidores locales mediante este aplicativo web con una interfaz intuitiva que incluye:
* **Sistema de Login Doble:** Acceso diferenciado para productores y consumidores.
* **Interfaz Adaptativa:** Diseño moderno utilizando una paleta de colores en tonos teal.
* **Gestión de Usuarios:** Registro y validación de credenciales.

## 🛠️ Tecnologías Utilizadas
* **HTML5:** Estructura semántica del aplicativo.
* **CSS3:** Estilo visual personalizado (archivo `styless.css`).
* **JavaScript (JS):** Lógica de autenticación y manejo de eventos.
* **Git & GitHub:** Control de versiones y despliegue.
